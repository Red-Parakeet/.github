Red Parakeet is an offensive security collective born from a simple refusal: we were tired of proprietary black boxes, closed-source tooling, and an industry that gatekeeps knowledge behind paywalls.

What started as two operators and cold coffee became a collective that runs live offensive engagements **and** ships the open-source tools we build to run them. Every release is a commitment to transparency — and a challenge to the status quo.
